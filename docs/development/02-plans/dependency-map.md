# 工作流依赖与并行波次

## 可并行关系

```text
WS-00 契约与协调 ─────────────┐
WS-01 前端模块化 ─────────────┼─> WS-05 客户端产品化
WS-08 QA/安全基线 ────────────┤
WS-07 合规/支付调研（独立）    │
                              │
WS-02 账号与会话 ─────────────┼─> WS-03 需求/报名/选人
                              ├─> WS-04 消息/通知
WS-03 需求/报名/选人 ─────────┼─> WS-06 文件/交付/验收
                              └─> 全流程端到端验收
```

## 合并优先级

1. WS-00 的共享契约；
2. WS-01/WS-08 基线；
3. WS-02 与 WS-03 服务端核心；
4. WS-05 前端接入；
5. WS-04 与 WS-06；
6. WS-07 只有 ADR 获批后才产生支付实现任务。

## 冲突热点

- 根目录 `app.js/index.html/styles.css`：只允许 WS-01 或其后 WS-05 的单一任务持有。
- `src/shared/**`：仅 WS-00 契约任务修改。
- 数据库迁移序号：由协调者预留区间，避免两个工作流创建同号迁移。
- E2E 测试主流程：WS-08 所有；功能工作流新增场景前先与 QA 协调文件名。
