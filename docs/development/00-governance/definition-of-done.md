# 完成标准（Definition of Done）

任务只有同时满足以下条件才算完成：

1. 范围：只修改已认领路径，无未说明的附带变化。
2. 功能：任务验收条件全部通过，失败路径有明确处理。
3. 测试：新增/更新相应测试并实际运行；结果写入交接文件。
4. 兼容：涉及界面时验证桌面与 390px 手机视口、键盘操作和空状态。
5. 安全：鉴权、输入校验、越权、敏感日志和文件边界已检查。
6. 数据：迁移可重复、状态迁移合法、时间/金额格式符合约束。
7. 契约：API 和领域类型与共享契约一致；破坏性变化有版本/迁移方案。
8. 文档：用户行为、运行方式和已知限制同步更新。
9. 证据：交接文件包含命令、通过/失败结果、截图或日志位置。
10. 清理：无调试账户、密钥、临时数据库、悬挂服务和无意义生成物。

协调者根据风险可以增加验收项，但不得跳过上述底线。
