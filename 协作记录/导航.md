# 协作记录导航

这里保存会随开发过程持续变化的记录。固定规则放在 `文档/开发协作/`，机器入口放在 `.agents/`，人员、任务、核对和确认记录全部放在这里，便于查看、审计和回溯。

| 分类 | 权威文件 | 用途 |
|---|---|---|
| 人员与对话 | `人员与对话/人员登记表.md` | 说明谁在修改、通过哪个对话修改、负责什么 |
| 任务进度 | `任务进度/任务板.json`、`任务进度/开发进度总表.md` | 机器与人工查看开发状态、依赖、分支和进度 |
| 任务认领 | `任务认领/认领-<任务号>-<修改人编号>.json` | 防止不同人或不同对话同时修改相同范围 |
| 核对结果 | `核对结果/核对-<任务号>-<日期>.md` | 保存测试命令、结果、差异和风险 |
| 修改确认 | `修改确认/确认记录/确认-<任务号>-<实现提交短哈希>.md` | 请求项目所有者确认本次修改和回退点 |
| 交接记录 | `交接记录/交接-<任务号>-<日期>.md` | 让下一位开发者继续工作 |

任何任务都不得直接从“开发中”跳到“已完成”。完成开发后必须依次经过“待核对”“待确认”，由项目所有者确认后才可合并并标记“已完成”。
