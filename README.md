# 算力集

以作业辅导与协作完成为主要入口，同时支持其他合法开发、数据、AI、设计与算力需求的任务协作平台原型。

## 快速体验

- 电脑端：双击 `启动原型.cmd`。
- 手机端：手机与电脑连接同一 Wi-Fi，双击 `手机联调.cmd`，再访问窗口显示的地址。
- 所有演示数据保存在当前浏览器，不会产生真实交易。

## 已实现的原型流程

`发布需求 → 多人初版报名 → 发布方比较选人 → 订单内沟通 → 提交成果 → 修改/验收 → 演示付款 → 完成`

- 同一账号可以发布需求，也可以报名参与其他订单；
- 报名包括初步思路、小样、报价和预计时间；
- 发布方选人后，双方可以在订单内对话；
- 支持交付、退回修改、验收和演示付款；
- 同一套界面适配电脑和手机。

## 当前开发边界

当前是本地交互原型，不包含真实多用户服务器、真实文件存储、真实身份认证和真实支付。充值、提现、余额、付款码和担保状态均为演示。

## 协作开发

任何新开发者或新对话都必须先阅读 [AGENTS.md](AGENTS.md)，登记修改人编号，认领独立任务，并在完成后提交核对报告和修改确认单。没有确认记录的修改不能合并到 `main`。

机器入口保存在 `.agents/项目入口.json`；`.agents` 是工具固定技术目录，可变进度和人员记录统一保存在中文 `协作记录/` 目录。
