# 算力集（ComputeHub）交互原型

这是一个以作业辅导与协作完成为主要入口、同时支持其他真实需求的双边服务平台原型。同一个账号既可以发布需求，也可以提交初版报名；发布方比较候选人的思路、小样、报价和时间后选定一人，再进入订单沟通、交付与验收。

## 直接体验

双击 `启动原型.cmd`，浏览器会自动打开 `http://127.0.0.1:4173`。

手机与电脑连接同一 Wi-Fi 后，可双击 `手机联调.cmd`，按窗口显示的局域网地址在手机浏览器打开。首次启动时若 Windows 防火墙询问，只需允许专用网络。

如果电脑没有 Python，也可以直接双击 `index.html`。核心流程仍可使用，但安装为 PWA 和离线缓存需要通过本地服务访问。

首次进入会显示 4 个演示身份。推荐先以“陈默”登录：

1. 以“陈默”打开 Python 作业辅导需求并提交初版报名；
2. 切换到“林知夏”，在“我发布的”订单中比较报名并选定陈默；
3. 选人后进入订单沟通，发送题目、进度和修改相关消息；
4. 切回陈默提交交付物，再由林知夏验收；
5. 使用演示付款码确认结算并结束订单。

所有数据只保存在浏览器 `localStorage` 中。账号面板提供“重置演示数据”。

## 当前原型覆盖

- 免密码演示登录与多身份切换
- 作业辅导优先、其他需求开放的协作广场
- 分类、搜索、预算和截止时间排序
- 初版报名、修改报名、多人比较和发布方选人
- 选人后的订单内双向对话
- 发布、报名、选人、交付、退回修改、验收、确认结算状态流
- 完成后付款码、余额、充值与提现的非真实演示
- 桌面侧边栏布局和手机底部导航布局
- PWA 清单、离线缓存与本地持久化

## 产品状态模型

`开放报名 → 发布方选人 → 进行中/订单对话 → 待验收 → 待付款 → 已完成`

每位候选人先提交初步计划、初版内容或小样、报价和预计时间。发布方只能选定一人，选人后双方才能进入订单对话。当前新订单使用完成后确认结算；旧演示数据中的担保状态仅用于保留界面参考。

## 生产化边界

本目录是前端交互与商业流程模型，订单对话只保存在当前浏览器；不包含真实支付、真实提现、实名认证、风控、文件存储和服务端数据库。正式上线时至少需要：

- 服务端账号与权限、订单状态机和审计日志；
- PostgreSQL、对象存储、消息与通知服务；
- 接入持牌支付机构的分账/担保交易能力，不能由普通平台自行沉淀用户资金；
- 实名认证、合同、发票、退款仲裁、风控和内容审核；
- 对交付文件做病毒扫描、访问授权与留存策略；
- HTTPS、数据备份、监控告警和隐私合规。

建议验证市场需求时，第一版先聚焦一种高频场景（例如数据标注或 GPU 算力租用），不要一开始覆盖所有 AI 服务。

更完整的业务规则、数据模型、生产架构和 MVP 节奏见 `产品方案.md`。
