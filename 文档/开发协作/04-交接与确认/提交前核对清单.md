# 提交前核对清单

完成计划后必须暂停扩展范围，依次核对以下内容并把结果写入 `协作记录/核对结果/`。

## 一、身份和范围

- [ ] 修改人、对话、任务、分支、认领文件互相一致。
- [ ] 实际文件都位于任务负责路径内。
- [ ] 已检查工作区中的用户既有修改，未覆盖或误提交。
- [ ] `git status --short` 只显示本任务内容。
- [ ] `git diff --check` 无空白错误。

## 二、功能与数据

- [ ] 所有验收条件逐条验证。
- [ ] 正常路径、失败路径、空状态和边界输入有处理。
- [ ] 状态迁移、权限和数据持久化符合契约。
- [ ] 未启用未经批准的真实支付、托管、充值或提现。

## 三、测试与兼容

- [ ] 语法或静态检查通过。
- [ ] 与修改相关的自动测试通过。
- [ ] 涉及界面时完成桌面端和 390px 手机端验证。
- [ ] 浏览器控制台和服务日志没有新增错误。
- [ ] 治理校验脚本通过。

## 四、提交与回退

- [ ] 核对报告已经保存且结论为“通过”。
- [ ] 只暂存核对过的明确路径，不使用无差别暂存。
- [ ] 实现提交格式为 `[任务号][修改人编号] 中文摘要`。
- [ ] 实现提交后创建修改确认，并记录提交哈希和 `git revert` 回退方法。
