# 总开发路线图

## 里程碑 M0：并行开发基础

目标：建立 Git 基线、模块目录、共享类型、测试命令和稳定领域/API 契约。

退出条件：前端单体可拆分开发；任务板/认领/交接机制通过检查；现有浏览器流程不回归。

## 里程碑 M1：真实多用户核心

目标：服务端账号、会话、需求、报名、选人与数据库持久化。

退出条件：两个浏览器会话使用不同账号完成“发布 → 报名 → 选人”；越权和并发双选测试通过。

## 里程碑 M2：订单协作

目标：订单消息、通知、交付版本、文件和验收。

退出条件：历史消息跨设备可见；文件权限正确；退回修改保留版本；桌面/手机端全流程通过。

## 里程碑 M3：审核与运营

目标：作业合规审核、举报、禁售规则、风控事件和运营后台。

退出条件：违规类型可拦截/下架；审核操作有审计；隐私与内容保留策略完成。

## 里程碑 M4：结算决策

目标：比较持牌支付服务商和交易结构，完成法律/财务/技术 ADR。

退出条件：服务商、资金托管、退款、分账、提现、风控和失败处理全部明确。未通过则继续保持演示结算，不进入真实支付开发。

## 里程碑 M5：上线准备

目标：生产部署、备份恢复、监控告警、安全测试、隐私条款和运营手册。

退出条件：恢复演练、负载测试、安全检查、发布回滚和目标环境验收通过；有明确公网 URL 才能描述为已上线。
